# 紀行プランナー

原神の紀行が目標Lvに届くかを、ゲームの画面から拾った数字だけで計算する静的サイト。

## 入力

紀行画面に出ている3つの数字を入れる。ほかに聞くことはない。

- 紀行レベル
- 紀行経験（「紀行経験 340 / 1,000」の分子）
- 今週の獲得経験値（「今週の獲得経験値 5,200 / 10,000」）
- 今日のデイリーを消化済み（チェックすると今週の残り日数から今日を除く）

目標Lv・冒険ランク・シーズン終了日時は「設定」の中。購入プランは計算に入れない。現在の紀行Lvを申告してもらうので、真珠の歌のLv+10も入力済みのLvに含まれている。

## 問診票

「問診票を回答する」ボタンで開くダイアログで、12の質問を2ページに分けて聞く（1/2 シーズン任務、2/2 ウィークリー）。次へ・戻るで移動し、最後は完了で閉じる。はい／いいえで答えると、シーズン任務とウィークリーの選択が埋まる。表はそのあと手で直してよい。常時出すと場所を取るので、ボタンの後ろに置いている。ボタンには「はい N / 12」を出す。

- シーズン任務に効く: イベント任務をやる（既定はい）、聖遺物を強化する（既定はい。原石報酬があるため）、深境螺旋、幻想シアター、幽境の激戦（既定いいえ）
- ウィークリーに効く:
  - ガチャを回す → モラ50万は今週だけ。育成で自然に使うため
  - 七聖召喚（既定いいえ）、他人の壺で買い物（既定いいえ）、調度品を作る（既定いいえ）
  - 秘境・ボス・地脈を周回する（既定いいえ）。虚無周回を避ける
  - 料理を作る（既定はい。獣肉を焼くだけで足りる）、鍛造を頼む（既定いいえ。鉱石集めが要る）
- 質問しないもの: 樹脂1,200個と洞天宝銭1,000枚。デイリーを回していれば自然に貯まる

## 計画をURLで共有

「この計画のURLをコピー」を押すと、いまの状態を `#p=...` に詰めたURLを作ってクリップボードに入れる（約160文字）。開いた側は、3つの入力・問診票の回答・ウィークリーとシーズン任務の選択がそのまま復元される。

- 中身は base64url にしたJSON。数値、回答、任務ごとの状態だけを入れ、サーバーは使わない
- 基準日時（設定の「基準日時」）は共有しない。相手の日付で計算される
- 読んだハッシュはすぐ消す。残すと再読み込みのたびに古い計画で上書きされるため
- 任務の数が変わった古いURLは黙って無視する（`v` と文字数で判定）

## 何を目指しているか

目標Lv（既定は50）に、シーズン終了までに届くことだけを見る。週上限10,000を埋めることは目標にしていない。早く着けば余り、届かなければ不足で、どちらも着地点バーに出す。

ウィークリーの表は「今週」と「来週以降」の2列。今週は 済／やる／やらない、来週以降は毎週やるものにチェックを付ける。

表の上に、目標までの残りと1週あたりの必要量を出す。`目標まで 38,660 EXP ／ 残り5週 ／ 1週あたり 7,732 EXP 必要`。

そのうえで、抜ける量を2本出す。基準は週上限ではなく目標Lvで測る。

- `今週は あと N EXP まで抜ける` — 今週の列だけで測る
- `来週以降は あと N EXP まで抜ける` — 毎週残す分で測る
- 全部抜いても目標に届く場合はそう出る。目標に届かない構成なら赤字で不足分を出す

抜いた分だけ各週の加算が減るので、着地点が目標を割る直前までが抜ける量になる。上限に届かなくても目標に届くなら、それは不足ではない。

## シーズン任務

週上限の対象外で、全部やると16,800 EXP。問診票で「やる」にしたものだけが対象で、表から個別に変えられる。済は現在のレベルに含まれているものとして加算しない。期限を過ぎた「やる」は計算に入れず、その旨を結果に出す。

並び順は `data/season.json` の順。イベント → 聖遺物 → 祈願 → 高難度（幽境 → 深境螺旋 → 幻想シアター）。期限と経験値で自動整列すると常設がイベントに挟まれるので、ファイルの順をそのまま使う。

## 画面

1ページ。上から入力、問診票、シーズン任務、ウィークリー、累計EXPのグラフの順に並ぶ。シーズン任務は一度決めれば動かないので先、ウィークリーは毎週見直すので後ろに置いている。

グラフは横軸が週、縦軸が累計EXP。今の累計から週ごとの着地をつなぎ、目標Lvの線を重ねる。何週目で届くかがそのまま読める。

計画着地点（Lv・到達日・余り／不足・シーズン任務を除いたLv）は画面下に固定する。入力を触っている間も答えが見える。入力すると即座に計算し直し、値はブラウザに保存する。

## 構成

```

src/style.css             ライト系フラットの見た目

data/season.json          シーズン任務・ウィークリー・デイリーのデータ
build.mjs                 data と src を dist/index.html にまとめる
test/calc.test.mjs        計算ロジックのテスト
test/ui.test.mjs          画面のテスト（jsdom）
.github/workflows/ci.yml  push/PR のテストとビルド
.github/workflows/pages.yml  GitHub Pages へのデプロイ
dist/                     生成物（コミットしない）
```

## ローカル

```sh
npm ci
npm test
npm run build
# dist/index.html をブラウザで開く
```

開発依存は `jsdom` のみ。実行時の外部依存はない。Node は22.22以降（jsdom 31の要件）。

## テストとCI

- `test/calc.test.mjs` — 日付境界、週上限、今日のデイリー、ウィークリーの取捨、シーズン任務、期限切れ、AR、シーズン終了後。
- `test/ui.test.mjs` — 3つの入力、着地点の更新、2列のウィークリーと2本の残り表示、シーズン任務の切り替え、設定、週の内訳、保存。
- `npm test` は計算テスト → ビルド → 画面テストの順に実行する。
- `ci.yml` は push / pull request で `npm ci` → `npm test` → `npm run build`。
- `pages.yml` は `main` への push でテスト・ビルドし、`dist` を Pages にデプロイする。

## GitHub Pages

1. `main` に push する。
2. リポジトリの Settings → Pages → Build and deployment → Source を **GitHub Actions** にする。
3. `pages.yml` が `dist` を公開する。

## シーズン更新

編集するのは `data/season.json` だけでよい。

- `season`: シーズン番号・名前・開始/終了・表示ラベル・確認日・Wiki更新日。
- `seasonMissions`: 任務名、紀行経験、`from`、`deadline`、`cat`（`event` / `hard` / `fixed`）、メモ。
- `weekly` / `daily`: 任務内容や経験値に変更があったときだけ。

`from` / `deadline` は JST の `YYYY-MM-DDTHH:mm`。`deadline` はゲーム内の期限に合わせる。イベント自体がシーズン終了後まで続く場合でも、紀行の期限はシーズン終了日にする。

更新したら `npm test` と `npm run build` を実行する。テストには現在シーズンのスナップショット（デイリー695 / ウィークリー6,795 / シーズン16,800）があるので、値が変わったら見直す。

## 計算ルール

- 紀行経験1,000でLv+1。上限Lv50（合計49,000 EXP）。
- デイリーとウィークリーは月曜05:00（JST）からの1週間で10,000まで。超えた分は加算されない。
  - アジアサーバーの04:00リセット（UTC+8）がJSTでは05:00。
- シーズン任務は週上限の対象外。
- デイリーは4任務すべてで1日695 EXP、週4,865 EXP。
- 購入プランは計算に入れない。真珠の歌のLv+10は購入時に即時適用されるので、入力するLvに含まれている。

## データの注意

- 対象はシーズン54「聖霊紀行」（2026-11-04〜2026-12-14 04:59）。
- デイリー・ウィークリー・報酬は原神Wiki「紀行」（2026-11-04更新）を基準にした。
- ウィークリーの合計は6,795。Wiki本文の「7,695」はVer.5.0で「住民リクエスト」「討伐懸賞」が削除される前の値。現在の表の任務を足すと6,795になる。
- ウィークリーの回数は秘境10回／地脈の花芽15回（Luna Iの緩和後）。経験値はどちらも450。
- 幽境の激戦「激戦の功勲1,200」は地脈活動期（11/11 11:00〜11/21 04:59）のみ。期限を11/21にしている。
- 幻想シアター第8幕は12/1開放。深境螺旋は11/16以降の期でもよい。
